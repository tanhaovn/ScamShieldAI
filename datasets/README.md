# Datasets

- `phishvn/`: bản dữ liệu và model tham chiếu PhishVN dùng cho nghiên cứu/huấn luyện.
- `vietnamese_sms/`: dữ liệu tin nhắn tiếng Việt.
- Dataset ảnh huấn luyện cục bộ có thể đặt tại `phishing_dataset/`; thư mục này
  bị Git bỏ qua vì dung lượng lớn và có thể chứa dữ liệu chưa công bố.

Model đã chọn để ứng dụng chạy phải được xuất sang `models/`.
